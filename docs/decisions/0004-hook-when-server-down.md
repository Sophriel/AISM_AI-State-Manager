# 0004. 서버가 꺼져 있을 때 훅은 잠깐 재시도 후 멈춤 허용

- 상태: 확정
- 날짜: 2026-11-11

## 결정

Stop 훅이 AISM 서버에 연결하지 못하면 짧게 재시도한 뒤(기본: 1초 간격 3회, 최대 약 3초), 그래도 안 되면 **멈춤을 허용**한다(아무것도 출력하지 않고 exit 0).

## 결과

- AISM이 꺼져 있어도 세션은 평소처럼 수동으로 쓸 수 있다.
- 서버 재시작 직후 몇 초간의 공백은 재시도로 흡수한다.
- 대가: 서버가 꺼져 있을 때 응답 끝마다 최대 약 3초 지연. 재시도 횟수·간격은 설정값으로 둔다.
