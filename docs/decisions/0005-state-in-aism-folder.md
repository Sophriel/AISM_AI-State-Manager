# 0005. 오케스트레이터 상태는 AISM 쪽에 저장한다

- 상태: 확정
- 날짜: 2026-11-11

## 결정

- **AISM 폴더(`state/`)**: 작업별 진행 단계, 루프 횟수, 세션 ID, 이벤트 이력 등 오케스트레이터 내부 상태.
- **대상 레포의 플랜 폴더**: 역할 세션이 주고받는 산출물(plan-vN / plan-vN-verify / todo / code-log)만 (ADR 0006).

## 이유

대상 레포(EWE 등)의 `git status`를 오케스트레이터 상태 파일로 더럽히지 않는다. 산출물은 사람이 읽고 커밋할 가치가 있지만 내부 상태는 아니다.

## 결과

- `state/`는 `.gitignore`에 이미 포함.
- 상태가 사라져도 산출물 파일에서 현재 단계는 복원 가능해야 한다 (Status 줄이 진실의 원천).
