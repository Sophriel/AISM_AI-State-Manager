# 0002. 상태 판정은 파일과 훅으로만 한다

- 상태: 확정
- 날짜: 2026-11-11

## 맥락

세션이 끝났는지, 결과가 무엇인지를 판단하는 방법은 (a) 터미널 출력 파싱, (b) LLM에게 판단시키기, (c) 산출물 파일 + 훅 이벤트가 있다.
(a)는 렌더링·스피너·도구 출력 때문에 불안정하고, (b)는 비결정적이다.

## 결정

- 세션 종료: Claude Code 훅 이벤트로 감지한다.
- 다음 단계: 플랜 폴더의 산출물 파일(최신 plan-vN.md `Status`, plan-vN-verify.md `판정`)을 읽어 상태 머신이 결정한다. 규약은 ADR 0006.
- 산출물 형식은 `.claude/roles/_workflow.md`의 계약을 따른다.

## 결과

- 역할 프롬프트가 파일 형식을 정확히 지키게 만드는 것이 신뢰성의 핵심이 된다.
- 형식이 깨진 산출물은 BLOCKED로 처리하고 사람에게 넘긴다.
